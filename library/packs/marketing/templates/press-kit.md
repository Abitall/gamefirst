# Press kit - <game> <version>

Copy per release; fill every row or write N/A. A blank row is a hold. A human
publishes the page. No secrets, no invented quotes, no platform the build cannot
run on.

## Fact sheet

| Field | Value |
|---|---|
| Title | |
| Studio and credits | |
| Release window | date or quarter; "TBA" needs an owner |
| Platforms | shipped targets only |
| Price | or "TBA"; a human sets it |
| Age rating | certificate and territory |
| Languages | shipped, with subtitles and audio marked |
| Build | MAJOR.MINOR.PATCH.BUILD and tag |
| Press contact | address, expected reply window |
| Store and site | URLs, each checked logged out |

## Media

- Logo: one file per background, light and dark.
- Capsule and key art: path, pixels, build or brand version.
- Screenshots: 6-10, real frames, each named by scene and build id.
- Trailer: URL, length, captions, music licence on file.
- GIF or short clip: optional, one, under 5s, no text.

## Description

- One sentence: what the player does.
- One paragraph: the loop, the tone, the scope.
- Three differences, each with a screenshot or clip reference.
- What it is not: the honest limit, one line.

## Company

- Team names and roles as they should be printed.
- Address for legal notices.
- Social and community links, checked on the day.
- Previous work, if any, with links.

## Rules

- Every claim links to a build, a screenshot, or a measurement.
- An award or quote names the source, the date, and the permission.
- A price or release date is typed by a human, never by an agent.
- Store rules change: re-read the holder's page before publishing.
