# Руководство

gamefirst v0.3: сначала играбельная петля, потом документы. Эта страница — ориентир; правила — в `AGENTS.md`, карта — в `/help`.

## Установка

Нужны Node 18+ и OpenCode.

1. Из корня gamefirst создай игру:
   `node tools/new-project.mjs ../my-game --name "Моя игра" --packs core,game --git`
2. Открой `my-game` в OpenCode: `AGENTS.md` — контракт проекта.
3. Введи `/start`: он прочитает `STATE.md` и `BRIEF.md`, предложит режим и задаст не больше трёх вопросов.

`core` ставится всегда; `game` добавляет навыки, crews и гейты.

## Первая игра

`BRIEF.md` (идея и тест успеха) → прототип → G1. До G1 игру описывает `BRIEF.md`; `GAME.md` пишется после того, как человек сыграл петлю. Одна сессия — один шаг из `STATE.md`.

## Шесть команд

| Команда | Что делает |
|---|---|
| `/start` | онбординг, режим, чтение `STATE` и `BRIEF` |
| `/status` | фаза, активные части, гейт, следующий шаг, блокеры |
| `/next` | одно действие из `STATE` и `BACKLOG` |
| `/verify <claim>` | build, типы, тесты, evidence; иначе FAIL |
| `/retro` | пять строк и файл в `docs/retro/` |
| `/help` | карта файлов, команд, правил, режимов |

## Режимы

- **Обычный режим** — человек в цикле: `discuss`, `prototype`, `production`, `review`; не больше трёх вопросов на этап (R2), решение на гейте за человеком.
- **autonomous** — только с контрактом R10 в `STATE.md`: цель, границы, done, stop, бюджет, чекпойнты. Лог — `runs/AUTONOMY.jsonl`.

`mode > rules > skill > pack > docs`.

## Где что лежит

- `STATE.md` — фаза, режим, гейт, следующий шаг, блокеры.
- `BRIEF.md` — идея, петля, аудитория, критерий остановки.
- `DECISIONS.md` — почему так; только дописывать.
- `BACKLOG.md` — идеи вне скоупа с ценой.
- `GAME.md`, `TASTE.md` — что за игра и как ощущается; после G1.
- `docs/systems`, `docs/playtests`, `docs/engine` — механики, сессии, движок.

## `BLOCKING`

`BLOCKING — причина`: работа стоит, нужен ответ человека. Ответь на вопрос или дай недостающий файл; не проси повторить. После трёх неудач агент останавливается сам (E08).

## Гейты

Гейт — решение человека: строка с датой; агент его не ставит.

- `G1 fun` — оставить, убить, перенастроить или один раз расширить.
- `G2 slice` — идти, чинить или менять курс.
- `G2.5` — не гейт: фича-фриз, дальше контент и полировка.
- `G3 ship` — выпускать или держать.
