# S06 - Justification

Every semantic unit of `artifact/library/game/skills/brainstorm/SKILL.md` is justified below. "Source" names the rule, blueprint line, or researched artifact the unit rests on; where the unit is a synthesis, it says so.

## Deliberate omissions

| Omitted | Why | What covers the need |
|---|---|---|
| A worked example or sample 20-list | A sample set becomes the answer; the value is in writing them, not reading them. | R7 states the floor; the artifact is the written list. |
| A scoring matrix for candidates | Scoring is judgment, and judgment begins after the set closes. | A04 critiques; the brief carries one recommendation with a cost. |
| A GDD skeleton or section list | One page per document (R5); the GDD is A02's system cards. | D06 system card; A02 |
| Engine, platform or tech guidance | The game layer stays engine-agnostic; engine choice is its own stage. | S07 |
| A meeting or facilitation script | The tool is the artifact, not the workshop; a script doubles the page for no decision. | R7 set rules; the steps here |
| A catalogue of ideation techniques | Choosing a technique is taste, and a catalogue makes the skill heavy. | R7; the four variation axes in step 3 |
| Restated R7 rationale ("first idea is the most available") | One fact, one place; the rule already argues it. | R7 |
| Art, audio or narrative direction | Other layers own them; a brief may name a feeling, not a style guide. | A02, art and narrative modules |
| A backlog file format | R9 defines the entry (value and cost); the skill only routes to it. | R9 |
