## Finding

The gamedev rows give the numbers (SRC1, SRC2) and the feedback (SRC3) plus one working save-version scheme (SRC4). The software rows give the budget that fails a run (SRC5), the accessibility rule with an impact (SRC6) and the ordered migration (SRC7). The AI-agent rows give the fix gate (SRC8) and the declared test command (SRC9). No repository combines these into a polish round, and none supplies the freeze, the one-gap rule or the human feel pass; those come from G2.5, R1, R8 and R9. Two widely used budget tools (lighthouse, sitespeed) turned out to have dropped the artifact this skill needs, which is why the budget shape comes from a test tool instead of a web-performance one.
